# Step 3 Spec: Nature / Science Figure Aesthetics (Code-Enforced)

Load **only in Step 3**. All visual styling lives in `02_src/plot_style.py`—always import it and use its journal primitives instead of raw Matplotlib defaults. **Official contest rules in `00_problem/` always override generic palette/layout defaults** (e.g., strict pure-black-and-white vs. color figures).

## Journal Figure Standards (❌ Cheap Look → ✅ Nature / Science Craft)
- **Physical Sizing & Multi-Panel Composition**: ❌ 10 giant isolated single charts scaled down into unreadable tiny text → ✅ Compose cohesive 2–3 panel figures via `create_journal_fig(nrows, ncols, width="double"|"1.5col"|"single")` + `label_panels(axes, style="nature")` (bold **a, b, c**) so LaTeX/PDF embeds at `1.0\linewidth` with crisp native print typography.
- **Clean Layout, Pure Black Ink & Palette Split**: ❌ Heavy boxed legends + dark cross-hatch grids + neon/rainbow colors (or decorative green/teal paper typography) → ✅ Frameless legends (`frameon=False`) or `direct_label()`, subtle y-only gridlines, crisp pure-black spines/axes/ticks/panel letters (`#000000`), `JOURNAL_COLORS` for figure data series; use **`DOCUMENT_PALETTE_MONOCHROME`** (`#000000`/`#FFFFFF`) for formal monochrome contest PDFs/Word and **`DOCUMENT_PALETTE`** (Charcoal-Ink + Oxford Slate-Navy) for interactive HTML dashboards or non-monochrome reports.
- **Honest Uncertainty & Specialized Primitives**: ❌ Bare mean line, truncated bar y-axis, or indistinguishable near-identical absolute bars → ✅ Start absolute bars at $y=0$; plot signed difference bars (`proposed − baseline`) via `plot_delta_bars()` when series track closely across scales; plot 95% CI/IQR ribbons via `plot_with_ci()`; use `add_zoom_inset()` for local zoom, `plot_tornado()` for ±5%/±10% sensitivity, and `plot_diverging_heatmap()` (zero-centered `RdBu_r`) for correlations/interactions.
- **Figure 1 Architecture Roadmap**: ❌ AI raster image generators (blurry/garbled text) → ✅ Vector diagram via `plot_pipeline_diagram()` (or TikZ / Graphviz / Mermaid→SVG→PDF) reusing the exact `JOURNAL_COLORS` palette.
- **Final-Print Readability & Offline Dashboards**: ❌ Colliding Pareto/scatter markers, annotation-on-legend overlaps, unparsed `NaN`/`@@DATA@@` in HTML payloads, or out-of-sync dashboard labels → ✅ Cluster touching markers at final print size via `group_close_points()`, enforce legend-vs-text collision & boundary checks via `check_figure_layout()` (called automatically inside `save_fig()`), and ensure any offline HTML dashboard is zero-CDN, finite-JSON (`allow_nan=False`), syntax-checked (`audit_paper.py --check-html`), keyboard-accessible, viewport-tested, and policy-synced with the report.
- **Dual Export & Mandatory Visual Check**: Save via `save_fig()` (`.pdf` vector + 300-DPI `.png`), then **open and inspect EVERY `.png`** for overlapping labels, clipped legends/edges, tofu glyphs (`□□□`), or stale numbers.
