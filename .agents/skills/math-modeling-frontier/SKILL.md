# Math Modeling Frontier Workflow

> **Core Rule (Priority #0)**: **Problem statement, official contest rules, and required deliverables in `00_problem/` ALWAYS override any generic skill default** (palette, appendix length, layout, CSV format). Zero restriction on math/modeling creativity; balance low-context safety and verification fidelity EQUALLY with **mathematical derivation thickness, physics/literature parameter grounding, high-tension executive narrative, and lean curated appendices**.

## 1. Dual-Tier Roles & O(1) Relay Memory (Cross-Model Handoff)

- **`[F]` Flagship (Architect & Reviewer)** / **`[W]` Workhorse (Executor)**: `[F]` handles problem selection, first-principles formulation, escalations, Step 4 audit, and Step 6 audit; `[W]` handles setup, cleaning, coding, sweeps, plotting, and drafting.
- **3-Tier Memory (`handoff.md` / `00_plan.md` / `01_log.md`)**:
  1. `handoff.md` (**HOT — OVERWRITE every switch, HARD CAP ≤ 80 lines**, check via `audit_paper.py --check-handoff handoff.md`): Only file read first after switching (`Step | Next Role | Active Task | File Pointers | Verified Headlines | Do-Not-Repeat | Next 1-Line Trigger`).
  2. `00_plan.md` (**CANONICAL — read on demand**): Live rules from `00_problem/` (clear all `[EXTRACT FROM 00_problem/]` / `[待核验]` tags before Gate P1), **Prompt Sub-Question & Requirement Traceability Checklist**, `Q1→Qn` **Math Derivation Spine**, **Parameter & Weight Provenance Table**, Nomenclature, Experiment Duty Matrix, Gate status.
  3. `01_log.md` (**COLD — append-only, NEVER preload**): EDA premise stats, real DOI/URL provenance, circuit-breaker archive.
  - **Pointer-Only Rule**: Store paths to `03_outputs/metrics/*.json` & `figs/*.png` + 1-line scalars only; never paste raw tables or code.

## 2. Standard Modeling Workflow & 1-Line Triggers (`MM Step 1` – `MM Step 6`)

> Switching sessions requires **zero long prompts**: type `MM Step N` (printed at the bottom of `handoff.md`). Each trigger loads ONLY its authorized files.

- **Step 0 `[W]` Setup & Live Rules**: Run [init_project.py](./scripts/init_project.py) (`--lock-raw` on new raw files). Extract ALL `00_problem/` rules into `00_plan.md` Sec. 0 (body-vs-appendix page caps, support-ZIP raw exclusions, AI/commitment sheets, monochrome/color norms, conflict priority, dual clocks) + **Prompt Sub-Question & Requirement Traceability Checklist**.
- **`MM Step 1` (`[F]` Track Choice, EDA & Modeling → `Gate M`)**: *(Zero reference files loaded—full native IQ.)* Audit every official dataset column, supplementary method, and explicit/implicit prompt requirement; pick track. Inspect raw data & premises (`01_log.md`), separate cohorts & causal vs. post-hoc parameters, use exact integer-scaled units when precision is fixed, self-play 2–3 paradigms, lock one coherent `Q1→Qn` **Math Derivation Spine** (governing equations, objectives/likelihoods, analytical properties/identifiability, cross-task interfaces) + **Parameter & Weight Provenance Table** backed by real DOIs/URLs in `01_log.md` (ban ungrounded magic-number formulas). Write `handoff.md` → **HIL pause**.
- **`MM Step 2` (`[W]` Cleaning & End-to-End Baseline → `Gate P1`)**: Reproducible cleaning (`01_data/clean/`) + full `Q1→Qn` Baseline (`02_src/`, relative paths, `seed=42`, single-source tuned-hyperparameter config failing loud on missing keys, `NaN/Inf`/zero-denominator assertions → `baseline.json`) + independent black-box `verify.py` (reads raw inputs directly; `zip(..., strict=True)` / `zip_longest`, non-BOM `utf-8` uniform-decimal CSVs, replayable structured diagnostics, cold-start byte-identical replay). **No deep single-Q tuning until Baseline passes.** On pass: `git commit` + overwrite `handoff.md`.
- **`MM Step 3` (`[W]` Upgrades, Validation & Visuals → `Gate P2`)**: Load ONLY [visual.md](./references/visual.md) + `02_src/plot_style.py`. Run upgraded models & official-attachment/domain baselines under **identical scoring/clamping & nested inner-CV protocols**; verify **interior hyperparameter optima & boundary-pinning/identifiability**; run **orthogonal 1-flag-1-mechanism ablations**, chronological splits, paired intervals, stress sweeps, and non-dominance ranking under official priority → sync via [sync_metrics.py](./scripts/sync_metrics.py). Export `.pdf` + 300-DPI `.png` (checking legend/label collisions) and **inspect every `.png`**. On pass: `git commit` + overwrite `handoff.md`.
- **`MM Step 4` (`[F]` Pre-Writing Technical & Mathematical Audit → `Gate R`)**: *(Zero reference files loaded.)* Audit before writing: (1) **Prompt Coverage & Official Rules**: every sub-question, metric, and required deliverable satisfied verbatim; (2) **Math & Provenance**: first-principles derivations + properties/identifiability in every core task, real data/physics/literature provenance for every weight & constant, cross-task coherence, disconnected-band & graph-split checks; (3) **Statistical & Verification Fidelity**: matched scoring/nested-CV protocols, interior hyperparameters, single-source resample propagation, bidirectional boundary counterexamples, cross-event & same-timestamp fixed-point state sync, post-hoc invariance, code-to-prose exactness, tamper probes & cold-start replay. Defect → overwrite `handoff.md` back to `[W]`; only `Gate R = PASS` enters Step 5.
- **`MM Step 5` (`[W/F]` Isolated Paper Drafting → `Gate W-Draft`)**: Fresh session loading **ONLY** [writing.md](./references/writing.md) *(never `audit.md`)*. Enforce single-source rendering + load-time metric reconciliation and `00_problem/` rules first; deliver: (1) high-tension 4-beat Abstract written **last** (zero audit-log clutter), (2) derivation-rich body math, (3) explicit parameter/weight provenance & citations, (4) **lean curated PDF appendix** unless `00_problem/` mandates full code (manifest + proofs + core modeling code; full suite in Support ZIP excluding raw official files); monochrome-first formal paper styling (unless rules specify otherwise), page budget, wrapper-last math (`"\\"` absent), cross-platform fonts, standalone companion sheets (never forge signatures).
- **`MM Step 6` (`[F]` Independent Red-Team Audit & Seal → `Gate W-Audit`)**: Fresh read-only Flagship session *(prefer different model; snapshot SHA-256 & probe in temp copy)* loading **ONLY** [audit.md](./references/audit.md). Run [audit_paper.py](./scripts/audit_paper.py) (`--plan 00_plan.md --verify-raw . --metrics-dir ... --figs-dir ... --src-dir ... --check-csv ... --strict-csv --log ... --pdf ... --render-pdf ...`, plus `--body-start-page` / `--max-pages` / `--max-appendix-pages` / `--check-html`) → Stage 1 Hard Gate (Prompt/Rules + Facts/PDF) → **Stage 2 5-Axis Substantive Audit** → inspect rendered pages → seal PDF & Support ZIP.

## 3. Six Hard Guardrails (Mechanical Only)

1. **Anti-Stuck & Dynamic Pivot**: Smoke-test heavy solvers on small `N` with timeouts. Debug via `Repro → Root Cause → Single Fix` (no `try/except: pass`). After **3 failed fixes** on one bottleneck/timeout/residual anomaly, **STOP (Attempt #4 forbidden)** → hand back to `[F]` via `handoff.md` (`L1 Exact → L2 Mechanism approx + bound → L3 Analytical/MC interval`); log dead ends in `01_log.md`.
2. **Immutable Raw Data, Real Citations & Zero Fabrication**: `00_problem/` & `01_data/raw/` are **READ-ONLY** (write clean outputs to `01_data/clean/`). Every paper number comes verbatim from `03_outputs/metrics/`. Ground laws/weights/parameters in real verifiable literature (`01_log.md` DOI/URL)—never fabricate data or citations.
3. **Verify Before Claim**: Never report "done/passed" without exit code `0`, passing assertions, fresh outputs, and visual `.png` check.
4. **No Shortcut Excuses**: Never skip Baseline, sensitivity sweeps, PNG checks, or post-edit re-verification.
5. **Zero Internal Leaks**: Never mention `Gate`, `handoff.md`, `SKILL.md`, `00_plan`, `01_log`, `metrics.json`, `[F]/[W]`, `3-Attempt`, or `L2` in the manuscript.
6. **Deadline Guard (<8h)**: Freeze new modeling → lock `metrics/` → priority: `official prompt deliverables & rules > missing key plots > high-tension abstract > Stage 1 audit + PDF check > seal`. Tag skipped checks `[CONSTRAINED DELIVERY]`.
